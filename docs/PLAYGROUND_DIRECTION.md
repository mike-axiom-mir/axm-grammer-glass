# Grammar Glass Playground Direction

This file records the direction for the `sol/grammar-glass-playground-v1` AI-instance lane.

## Goal

Make Grammar Glass more explorable, playful and creatively useful while preserving the existing source, provenance, replay and authority boundaries.

## First playground layer

The first experiment is a **visual-only Gravity Probe** over a loaded recorded Grammar Glass snapshot.

A user can select several real grammar identities and temporarily bend the viewer around them. The probe may highlight existing direct influence carries, contact-memory paths, Draft Stars and lineage involving those grammars. It must not change the recorded cycle, create new evidence, rank grammars, execute candidates, or feed anything back into the Twister.

The design principle is:

`recorded snapshot -> explicit visual probe -> derived inspectable probe receipt -> no mutation`

The probe should feel playful and physical, but its truth boundary remains visible: bending the glass is not bending the evidence.

## Follow-on ideas for this same PR lane

- **Gravity Well**: selected grammars become a visual focus and nearby recorded atoms curve toward the probe lens.
- **Rift Scan**: isolate cross-grammar boundaries, contrasts and repulsions between selected grammars.
- **Star Hunt**: follow a Draft Star from contributing grammars through formation, mirror, candidate, sandbox and any Run Star.
- **Constellation Mixer**: select a handful of grammar identities and inspect the real relationships already present in the loaded snapshot without claiming a new candidate exists.
- **Visual Roll**: pick a temporary grammar set for exploration using UI randomness that is explicitly not evidence and not part of replay state.

These remain exploration surfaces unless a later explicit core contract is added and verified.

## Non-negotiable truth boundary

- no cycle mutation
- no automatic re-entry
- no automatic execution
- no ranking or winner selection
- no quality claim from brightness, proximity, animation or user selection
- no new semantic-equivalence claim
- no claim that a visual probe is a discovered executable program
- no hidden rewrite of existing Grammar Glass behavior
